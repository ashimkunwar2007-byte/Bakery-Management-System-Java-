Bakery Management System

A Java application for managing a bakery's cake orders and stock.

The system has a single role, the Admin. When a customer calls or visits the store, the admin enters the cake order details (customer, cake type, size, inscription, delivery or pickup, and add-ons) into the system. The admin also keeps track of the bakery's stock, and cakes can only be ordered when the required stock is available.

Main Features
Admin login and dashboard
Create, view, edit and cancel cake orders
Stock management with low-stock and out-of-stock notifications
Automatic stock update when an order is saved or cancelled
Cake and add-on menu management
Order reports for a selected date range

Built with Java.
